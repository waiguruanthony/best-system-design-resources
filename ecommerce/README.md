## Quick Links

- **Stack:** Laravel, Blade, Tailwind, Alpine.js, Filament, Daraja, Stripe
- **Payments:** M-Pesa (STK Push, Paybill), Cards (Stripe redirect)
- **Content:** Editable pages via Filament
- **Sold-out:** `stock_quantity` / `is_sold_out` on products
- **WhatsApp:** Floating button with pre-filled message for quick assistance
